# Clínica Salud Total — Chatbot IA

Chatbot de atención al cliente con IA para clínicas.
Responde consultas 24/7, atiende múltiples pacientes 
simultáneamente y conoce todo sobre el negocio.

## Stack
- Python + FastAPI
- Groq API (llama-3.3-70b)
- HTML + CSS + JS puro

## Funcionalidades
- Responde preguntas frecuentes automáticamente
- Historial de conversación por sesión
- Chips de acceso rápido
- Disponible 24/7 sin costo de personal

## Instalación local
```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

## Deploy
Backend desplegado en Railway.
Frontend en GitHub Pages.
